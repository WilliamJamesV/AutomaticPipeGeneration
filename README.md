# Installation guide

- Download the zipped file, and unzip it. 

- Open an Autodesk Fusion project, then click Shift + S to open the 'scripts and add-ins' window. (Or go to Utilities > Scripts and Add-ins)

- Click on the '+' at the top of the window, and select script or add-in from device.

- Choose the unzipped file that was downloaded earlier.

The add-in 'PipePathAddIn' should now appear in the 'Scripts and Add-ins' window. Turn it one for the remaing part of your current Fusion session by turning it on once on the sliding bar once, or cross off 'Run on startup' for the add-in to be available when Fusion is opened. 

To run the add-in, go to the Solid > Voxel Pipe Path. The icon for the add-in should appear in the top menu, and also under Solid > Create > Voxel Pipe Path.
